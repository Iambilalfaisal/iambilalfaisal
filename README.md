## 🚀 Currently Building

### Document Intelligence Platform for Professional Services *(in development)*

A RAG-based platform aimed at law firms, CA/accounting practices, and other document-heavy niches: upload the firm's documents, ask questions in plain language, get answers with citations back to the source — turning hours of manual document review into a conversation.

Built on top of Microsoft's production RAG reference architecture, which I forked and use as the technical foundation while extending it toward this vertical use case:

- **Retrieval** — Azure AI Search over indexed firm documents
- **Generation** — Azure OpenAI Service, grounded strictly in retrieved context
- **Ingestion** — Azure AI Document Intelligence + Blob Storage for multi-format document upload
- **Trust layer** — every answer returned with inline citations back to source paragraphs
- **Access control** — Microsoft Entra identity integration

**Repo (technical foundation):** [github.com/Iambilalfaisal/Project-Ease](https://github.com/Iambilalfaisal/Project-Ease)
